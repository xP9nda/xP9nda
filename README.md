## About

I am a programmer with a passion game development, my main interest is in UI creation and implementation, and I also enjoy making mechanics and systems.

Currently I am a student at [University of Staffordshire](https://www.staffs.ac.uk), studying [BSc (Hons) Games Development](https://www.staffs.ac.uk/course/computer-games-development-bsc).

Alongside my studies, I work on personal projects through my indie studio on Roblox, pixl games, run with my brother, where I focus on programming and UI design and implementation.

When I'm not studying, I enjoy playing video games, climbing with the Uni society, and creating smaller personal projects like games, mechanics, scripts and tools, to continue learning and improving my skills.
